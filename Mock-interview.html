Q1: How does FastAPI handle async requests with ASGI vs WSGI?
AI Critique: Strong technical explanation of uvloop and event loops. Mentioning concurrency vs parallelism made the answer stand out.
💡 Model Ideal Answer: FastAPI leverages Starlette and Pydantic on top of ASGI (Asynchronous Server Gateway Interface), allowing a single worker thread to handle thousands of concurrent I/O-bound requests via asyncio event loops without blocking worker pools like WSGI.
Q2: How do you prevent database connection pool exhaustion under high concurrency?
AI Critique: Good mention of SQLAlchemy async engines, connection pool sizing, and PgBouncer connection multiplexing.
💡 Model Ideal Answer: Use asynchronous drivers (asyncpg), configure pool overflow and timeout bounds, leverage PgBouncer for transaction-level pooling, and ensure sessions are strictly closed inside context managers.
